# Discover the Land of Jesus — 2026 revival

Modern PWA + website + admin for the year-2000 CD-ROM "Discover the Land of Jesus" (by Fadi & Sami).
Content lives in **Firestore** (project `discloj-11eb2`); photos/videos are static files; the site is hosted at
`https://clicksolutionspro.com/discloj/`.

## Folders

| Folder | What |
|---|---|
| `text/`, `photos/`, `Video/` | The original disc material (TXT in 5 languages, BMP, MPG) — source only, never uploaded |
| `app/` | The app/website (static, no build step): `index.html`, `js/`, `css/`, `sw.js`, `manifest.webmanifest` |
| `adminos/` | The admin (edits Firestore directly; changes show in the app immediately) |
| `tools/` | Scripts: `parse_texts.py` (TXT → JSON), `convert_media.py` (BMP→JPG, MPG→MP4), `import_firestore.mjs`, `build.mjs`, `serve.mjs` |
| `dist/data/content.json` | Parsed content (generated) |
| `dist/media/` | Converted media (generated): `photos/*.jpg`, `photos/thumbs/*.jpg`, `videos/*.mp4`, `cover.jpg`, `back.jpg` |
| `dist/site/` | **The deployable site** (generated by `npm run build`) — upload its *contents* to `/discloj/` |
| `firestore.rules`, `storage.rules` | Security rules (read: everyone; write: admin UID only) |
| `secrets/` | Service-account key for the Node import (git-ignored) |

## Commands

```bash
npm run parse      # text/*.TXT  -> dist/data/content.json
npm run media      # photos/*.BMP -> dist/media/photos, Video/*.MPG -> dist/media/videos (mp4)
npm run build      # assemble dist/site (app + adminos + data + media)
npm run serve      # build + serve dist/site at http://localhost:8080/  (adminos at /adminos/)
npm run import     # import content.json into Firestore (needs secrets/serviceAccount.json)
```

## Firestore data model

- `settings/site` — `title{lang}`, `subtitle{lang}`, `credits`, `cover`, `mediaBaseUrl`, `defaultLanguage`, `languages[]`
- `places/{an|bk|…}` — `code`, `order`, `title{lang}`, `videoCode`, `coverPhoto`, `lat`, `lng`, `published`
- `photos/{AN01…}` — `code`, `place`, `order`, `image`, `thumb`, `bible{mt,mk,lk,jn}`, `title{lang}`, `text{lang}`, `videoCode?`, `published`
- `videos/{INTRO|H00…}` — `code`, `order`, `title{lang}`, `files{lang: path}`, `places[]`, `poster?`, `published`
- `pages/{about|privacy|disclaimer}` — `title{lang}`, `body{lang}`, `published`

`image` / `files` values are either a path relative to `mediaBaseUrl` (e.g. `photos/AN01.jpg`) or an absolute URL
(e.g. a Firebase Storage download URL from an adminos upload).

## Deploy (first time)

1. **Firestore rules**: Firebase console → Firestore Database → Rules → paste `firestore.rules` → Publish.
2. **Content**: either `npm run import` (with `secrets/serviceAccount.json`) or sign in to adminos → Import / Export → "Import from site".
3. **Files**: `npm run build`, then FTP the contents of `dist/site/` to `clicksolutionspro.com/discloj/`
   (≈165 MB the first time; afterwards only changed files — media only when it changes).
4. **Auth**: Authentication → Settings → Authorized domains → add `clicksolutionspro.com`.
5. Optional uploads from adminos need Firebase Storage (Blaze plan) + `storage.rules`; otherwise upload media via FTP and type the path.

URLs: app/website `https://clicksolutionspro.com/discloj/` · admin `https://clicksolutionspro.com/discloj/adminos/`

## Native apps (Capacitor)

- `npm run native` — rebuild web bundle (dist/native-www) and sync into `android/` + `ios/`
- `npm run apk` — build a debug APK: `android/app/build/outputs/apk/debug/app-debug.apk` (install directly on a phone)
- Android release for Google Play: create a keystore, then `cd android && gradlew bundleRelease` → upload the .aab (needs a Google Play developer account, $25 one-time)
- iOS: open `ios/App/App.xcworkspace` on a Mac (Xcode + CocoaPods, `npx cap sync ios` first). Needs an Apple Developer account ($99/year). No Mac? Use a cloud build service (Codemagic / Ionic Appflow).
- App id: `com.clicksolutionspro.discloj` · name: "Land of Jesus" · icons/splash from `assets/` via `npx capacitor-assets generate`
- In the native app, media (photos/videos) streams from clicksolutionspro.com/discloj/media; texts come live from Firestore; the Bible + content.json are bundled for offline.
